# pdf_to_png_cli

将`pdf`导出成`png`图片

```
将`pdf`导出成`png`图片

Usage: pdf_to_png_cli.exe [OPTIONS] --input <INPUT>

Options:
  -i, --input <INPUT>    需要读取的pdf文件
  -o, --output <OUTPUT>  指定输出文件夹, 不指定则在原文件目录下输出
  -d, --dpi <DPI>        设置分辨率 (默认为 96, DPI 越高图片越清晰)
  -h, --help             Print help
  -V, --version          Print version
```
